# Admissibility

## Purpose

Admissibility determines whether a governance decision has sufficient independent evidence to be accepted as trustworthy.

Execution alone does not establish legitimacy.

A decision is admissible only when its authority, evidence, policy, responsibility, execution, and resulting outcome can be independently verified.

## Principle

Execution proves that something happened.

Admissibility proves that it should have happened.

## Requirements

A decision is admissible when:

- Authority is verified.
- Responsibility is continuous.
- Applicable policy is identified.
- Evidence is complete.
- Decision Replay succeeds.
- Execution matches the approved decision.
- State verification succeeds.
- Governance Receipt is valid.

## Failure Conditions

A decision is not admissible if:

- Authority cannot be verified.
- Responsibility chain is broken.
- Policy cannot be reconstructed.
- Evidence is incomplete.
- Decision Replay fails.
- Execution exceeded approved scope.
- State verification fails.
- Governance Receipt is invalid.

## Independent Review

An independent reviewer should reach the same governance conclusion using only the preserved evidence.

## Goal

Admissibility transforms governance from trust in process to trust in independently verifiable evidence.
